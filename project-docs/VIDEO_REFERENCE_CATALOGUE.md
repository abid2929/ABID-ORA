## Rules applied
- Adapt, never clone: every idea is rebuilt in Abidora’s own type, colour and motion language and fitted to the world’s purpose.
- Behaviour over looks: where a clip shows an interaction (dress-up, booking filter, door reveal, time-of-day), the interaction itself is built and tested.
- Performance: canvas/WebGL effects sleep off-screen and respect the visitor’s Calm motion setting.
- Each implemented item moves to TESTED only after it passes the world’s automated checks.
